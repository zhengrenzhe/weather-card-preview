# 天气卡片效果样稿

天气小组件的动态效果样稿，只用于预览，不是正式代码。

- [首页](index.html)：这一版。云是程序实时生成的，不用图片。
- [对比页](compare.html)：上一版和这一版并排。
- [上一版](photo.html)：云用实拍照片加工成的贴图，留着做对比。

## 这一版怎么画（2026-11-17 重新设计）

对照苹果天气量过之后，整个换了画法：

- **云**：程序生成的小朵薄云，有厚度（平底、圆顶），边缘是毛絮。沿视线穿过云层取 14 个点，朝太阳方向再取两点算明暗：朝着光的边亮，云肚子是带一点蓝的浅灰，不再是一整块纯白。画面按抬头看天的视角算，上边的云近、大，往下越远越小，融进天色。
- **太阳**：始终在卡片之外，只有洒进来的一片柔光，没有圆盘。有直射阳光时，太阳外面有一圈淡淡的日晕，左下方排着三个镜头光斑。上午九点到下午三点多在卡片正上方；更早、更晚时光从右下方来，不经过右上角的文字。
- **天空**：白天是比上一版略淡一点的蓝，顶上深、往下变浅；离太阳越远越暗一点。阴天是灰的，雨天更暗，云比天还暗。
- **雨**：一条条又细又直的雨丝。近处的雨丝落到第一排信息栏的顶边会停下，溅起三四颗小水珠；信息栏表面另有小水珠。
- **雪**：雪花分远近几层，远的小而慢、近的大而快；雪量越大每层越密、雪片越大，积雪也堆得更快更厚。暴雪是被风吹着斜飞的细丝，加一层顺风跑的雪雾。夜里雪片调暗。
- **冰雹**：白色小冰粒，落得比雨快；砸到第一排信息栏的顶边会弹起一两下，约一半停在边上，过几秒化掉。
- **雾、霾、沙尘**：一层慢慢飘的雾气，越往下越浓。霾偏暖灰，沙尘偏土黄并顺着风跑。
- **闪电、星月**：闪电从云里透出来；夜里有星星和月亮。

## 天气状态（2026-11-17 补全到 21 种）

画面由几个互相独立的量决定：云量、降水的种类和强度、风、雾气、有没有闪电。页面上的按钮只是这些量的几组取值，正式实现时由天气数据直接给。

| 分组 | 状态 |
| --- | --- |
| 天空 | 晴、少云、多云、阴 |
| 雾霾 | 雾、霾、沙尘 |
| 雨 | 毛毛雨、小雨、中雨、大雨、暴雨、太阳雨 |
| 雪 | 小雪、中雪、大雪、暴雪、雨夹雪 |
| 雷暴冰雹 | 雷阵雨、雷阵雨伴冰雹、冰雹 |

三个候选数据源能报出的每一种天气都能对应到上面某一种画面：Open-Meteo 的 29 个天气代码、苹果 WeatherKit 的 34 种状况、OpenWeather 的 55 个代码。没有单独画面、借用别的画面的：冻雨和冻毛毛雨用同强度的雨，阵雨、阵雪用同强度的雨、雪，烟和火山灰用霾，大风、炎热、严寒用当时云量对应的天空（风大时云飘得快），飓风、热带风暴用暴雨，龙卷风用雷阵雨。

霾和沙尘没有对照苹果天气量过（写这一版时它没有城市显示这两种状况），是按常理画的。

2026-11-17 修正：雪花原来是从下往上飘的。雪花那段着色器从上一版搬过来时，上一版的像素坐标 y 向上、这一版 y 向下，下落的公式没跟着改。

量出来的数（M4 Pro，大卡片，2 倍屏，每秒 30 帧）：

| | 上一版 | 这一版 |
| --- | --- | --- |
| 每帧显卡耗时，少云或多云 | 约 1.6 毫秒 | 约 1.3 到 1.5 毫秒（两次测量；日晕和光斑约占 0.05 毫秒） |
| 每帧显卡耗时，大雨 | 约 1.6 毫秒 | 约 1.3 毫秒 |
| 云的图片 | 7 张贴图 | 不需要；打开页面时算一张 256×256 的噪声图，约 25 毫秒 |

顶部白字的对比度（少云、多云正午，换 8 种云的位置量）：中位多在 4.5:1 到 5.1:1（多云时右上角两行约 3.5:1）；压在白云上的那一小部分（最差的 5%）约 2.3:1 到 2.9:1，偏低，正式实现前要定办法。

2026-11-17 第二轮调整：蓝天调蓝（比上一版略淡）、云调白、加日晕和镜头光斑、云飘动加快四成（少云时顶部约每秒 2.3 像素）。

## 性能与兼容性（2026-11-17 实测）

画面已定稿。下面是定稿之后量的（M4 Pro、Chrome 157、大卡片、2 倍屏、每秒 30 帧）。

一帧的显卡耗时（少云，共约 1.27 毫秒）花在三处：重画天空与云约 48%，磨砂面板约 35%，其余合成约 17%。

网址加 `opt=1` 可以打开三项试验中的优化，不加就是定稿时的画法：云每秒重画 10 次（原来 30 次）；磨砂面板背后的颜色随云一起按四分之一分辨率预先算好；画面没有变化的帧整帧不画。

| 每帧显卡耗时（毫秒） | 定稿时的画法 | 加 `opt=1` |
| --- | --- | --- |
| 晴 | 0.86 | 0.19 |
| 少云 | 1.27 | 0.33 |
| 阴 | 1.33 | 0.34 |
| 大雨 | 1.35 | 0.56 |
| 大雪 | 1.57 | 1.27 |
| 少云（小卡片） | 0.41 | 0.15 |

两种画法在固定时刻逐像素比较，最大差 2 到 3（满分 255）。大雪降得少，是因为雪花和云画在同一步里，这一步下雪时每帧都要重画。

其他量到的：

- 首帧：算噪声图 24 到 32 毫秒，建渲染器（含编译着色器）14 到 20 毫秒，第一帧 2 到 3 毫秒，都在主线程上。
- 没有显卡加速（软件渲染）时：大卡片每帧 33 到 67 毫秒，只能跑到每秒 15 帧左右，第一帧约 0.4 秒。正式实现要识别这种情况并改成静态背景。
- 浏览器的限制：电脑上的 Chrome 每个渲染进程最多 16 个活动的 WebGL 画布，同一个扩展开的所有页面共用这 16 个（实测）。
- 没测过：Windows、Linux、集成显卡。页面上主卡片下方会显示每帧耗时和显卡型号，可以在别的设备上打开看。

## 怎么看

- 顶部按钮切换天气、时间、尺寸和帧率，下方是和当前天气同一组的小卡片（一页里同时能开的 WebGL 画布有上限，21 种不能全开）。
- 网址参数，可以组合使用：
  - `cond`：天气。
    - 天空：`clear` 晴、`partly` 少云、`cloudy` 多云、`overcast` 阴
    - 雾霾：`fog` 雾、`haze` 霾、`dust` 沙尘
    - 雨：`drizzle` 毛毛雨、`lightrain` 小雨、`midrain` 中雨、`rain` 大雨、`downpour` 暴雨、`sunshower` 太阳雨
    - 雪：`snow` 小雪、`midsnow` 中雪、`heavysnow` 大雪、`blizzard` 暴雪、`sleet` 雨夹雪
    - 雷暴冰雹：`storm` 雷阵雨、`stormhail` 雷阵雨伴冰雹、`hail` 冰雹
  - `time`：时刻，0 到 24，例如 `6.7` 日出、`17.7` 黄昏、`22.5` 夜里
  - `size`：`s` 小、`m` 中、`l` 大
  - `gallery=0`：不显示下方的小卡片
  - `seed`：固定云的图案（同一个数两次打开云在同一处）；`freeze`：云停在这一秒不动
  - `bare=1`：只显示卡片
  - `sheet=partly@13,cloudy@17.7`：一次并排画几张
- 调参用：`scale`（小云的大小，越大云越小）、`mscale`（成片云的大小）、`thick`（云的厚度）、`fray` / `mfray`（云边毛絮多少）、`erode`（啃边）、`shadow`（背光压暗）、`expo`（白天云的亮度）、`vig`（离太阳远处压暗多少）、`glow`（太阳光的强度）、`halo`（日晕）、`ghost`（镜头光斑）、`speed`（云飘动的快慢）、`sres`（天空按 CSS 像素的几倍画，默认 1）、`skyhz`（每秒重画几次云，默认每帧都画）。
- `vary=scale:1|1.5|2`：同一个参数的几个取值并排比较。
- `opt=1`：打开试验中的优化（见上）。测量用：`skyhz=0.2`（云几乎不重画）、`nopanel=1`（不画磨砂面板）、`sync=1`（每帧等显卡画完再计时，脚本耗时里就含了画图的时间）。
