# 天气卡片效果样稿

天气小组件的动态效果样稿，只用于预览，不是正式代码。云用真实照片加工成的贴图，按时段和天气重新打光；下雨时雨滴会砸在卡片的面板上。

## 怎么看

- 顶部按钮切换天气、时间、尺寸和帧率，下方是全部天气的小卡片。
- 网址参数，可以组合使用：
  - `cond`：天气。`clear` 晴、`partly` 少云、`cloudy` 多云、`overcast` 阴、`fog` 雾、`drizzle` 小雨、`rain` 大雨、`storm` 雷阵雨、`snow` 小雪
  - `time`：时刻，0 到 24，例如 `6.7` 日出、`17.7` 黄昏、`22.5` 夜里
  - `size`：`s` 小、`m` 中、`l` 大
  - `gallery=0`：不显示下方的小卡片
  - `slowmo=8&droptest=0.8`：雨滴慢放 8 倍，并定时在面板中央砸一颗大雨点
- 例如 `?cond=rain&size=l&gallery=0&slowmo=8&droptest=0.8` 是大雨大卡片的雨滴慢放。
- `v=old`：看改之前的效果（旧贴图、旧配色、旧面板）。
- [compare.html](compare.html) 把改前、改后并排放在一起，两边云的位置相同。

## 2026-11-16 去掉"油腻感"

- 抠图：不再先模糊、不再把透明度拉对比。旧做法让薄云成了实心团块，云边一圈反解出天空的暗蓝，成了灰色描边。把贴图叠回原照片的天空上和原照片比，云边的平均误差从 0.037 降到 0.016。新贴图在 `tex3/`，旧贴图留在 `tex2/` 供对比。
- 配色：正午阳光从奶油色改成白色；云的暗部整体提亮，并按所在处的天空色染一点（白天偏蓝）。中性灰挨着饱和的蓝天会被看成发黄发褐。
- 面板：旧做法逐像素把亮处压暗，白云被压得和蓝天一样亮，成了褐灰色的团。改成大半径磨砂，按大片的平均亮度整体压暗，再带一点天顶的颜色，玻璃后的白云仍比蓝天亮。代价是每帧显卡耗时多约 0.3 毫秒（大卡片、2 倍屏，M4 Pro 上从 1.23 毫秒到 1.53 毫秒）。
- 调参用的网址参数：`depth`（云暗部保留多少，默认 0.55）、`ambSky`（背阴面染多少天空色，默认 0.4）、`frost`（面板模糊半径，默认 32）、`pmip`（按多大一片压暗，默认 7.5）、`pcap`（面板亮处软上限，默认 0.42）、`ptint`（面板带多少天顶色，默认 0.3）、`ofs`（贴图起始位置，固定后两次打开云的位置相同）、`bare=1`（只显示卡片）。
