# 天气卡片效果样稿

天气小组件的动态效果样稿，只用于预览，不是正式代码。

- [首页](index.html)：这一版。云是程序实时生成的，不用图片。
- [对比页](compare.html)：上一版和这一版并排。
- [上一版](photo.html)：云用实拍照片加工成的贴图，留着做对比。

## 这一版怎么画（2026-11-17 重新设计）

对照苹果天气量过之后，整个换了画法：

- **云**：程序生成的小朵薄云，有厚度（平底、圆顶），边缘是毛絮。沿视线穿过云层取 14 个点，朝太阳方向再取两点算明暗：朝着光的边亮，云肚子是带一点蓝的浅灰，不再是一整块纯白。画面按抬头看天的视角算，上边的云近、大，往下越远越小，融进天色。
- **太阳**：始终在卡片之外，只有洒进来的一片柔光，没有圆盘。上午九点到下午三点多在卡片正上方；更早、更晚时光从右下方来，不经过右上角的文字。
- **天空**：顶上是偏暗、不太饱和的蓝，往下变浅；离太阳越远越暗一点。阴天是灰的，雨天更暗，云比天还暗。
- **雨**：一条条又细又直的雨丝。近处的雨丝落到第一排信息栏的顶边会停下，溅起三四颗小水珠；信息栏表面另有小水珠。
- **雪、雾、闪电、星月**：雪花、信息栏顶边和卡片底边的积雪沿用上一版；闪电从云里透出来；夜里有星星和月亮。

## 怎么看

- 顶部按钮切换天气、时间、尺寸和帧率，下方是全部天气的小卡片。
- 网址参数，可以组合使用：
  - `cond`：天气。`clear` 晴、`partly` 少云、`cloudy` 多云、`overcast` 阴、`fog` 雾、`drizzle` 小雨、`rain` 大雨、`storm` 雷阵雨、`snow` 小雪
  - `time`：时刻，0 到 24，例如 `6.7` 日出、`17.7` 黄昏、`22.5` 夜里
  - `size`：`s` 小、`m` 中、`l` 大
  - `gallery=0`：不显示下方的小卡片
  - `seed`：固定云的图案（同一个数两次打开云在同一处）；`freeze`：云停在这一秒不动
  - `bare=1`：只显示卡片
  - `sheet=partly@13,cloudy@17.7`：一次并排画几张
- 调参用：`scale`（小云的大小，越大云越小）、`mscale`（成片云的大小）、`thick`（云的厚度）、`fray` / `mfray`（云边毛絮多少）、`erode`（啃边）、`shadow`（背光压暗）、`expo`（白天云的亮度）、`vig`（离太阳远处压暗多少）、`glow`（太阳光的强度）、`sres`（天空按 CSS 像素的几倍画，默认 1）、`skyhz`（每秒重画几次云，默认每帧都画）。
- `vary=scale:1|1.5|2`：同一个参数的几个取值并排比较。
